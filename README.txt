# إدارة البرج
نسخة أولية تعمل من المتصفح وتخزن البيانات محليًا على الجهاز.

## التشغيل
افتح index.html في Safari أو أي متصفح حديث.

## النسخة الحالية
- إضافة وتعديل المشتركين
- رقم الهاتف ورقم الاشتراك والباقة
- قيمة الاشتراك وتاريخ الاستحقاق
- تسجيل التسديد
- حساب دخل الشهر
- قائمة المسددين والمتأخرين
- سجل الدفعات لكل مشترك

## ملاحظة
هذه نسخة أولية محلية. لإرسال SMS/واتساب فعليًا، نحتاج لاحقًا ربطها بخدمة إرسال رسائل، ولحفظ البيانات بين أجهزة متعددة نحتاج قاعدة بيانات وخادم.
