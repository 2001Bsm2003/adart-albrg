# إدارة البرج

نسخة أولية تعمل مباشرة في المتصفح.

## التشغيل
افتح `index.html` في Safari أو أي متصفح حديث.

## المزايا الحالية
- إضافة المشترك.
- رقم الهاتف.
- الحساب.
- الباقة.
- المبلغ.
- تاريخ الاستحقاق.
- تسجيل التسديد.
- تعديل وحذف المشترك.
- البحث.
- حفظ البيانات محلياً على الجهاز.
- تصدير البيانات.

## مهم
هذه النسخة ليست قاعدة بيانات سحابية بعد. البيانات محفوظة في LocalStorage على الجهاز.

## الخطوة التالية
بعد التأكد أن الواجهة تعمل، نربطها بقاعدة بيانات حقيقية ونضيف حساب المدير ورسائل WhatsApp/SMS والفواتير.
